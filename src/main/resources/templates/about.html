About the Application

A simpler way to organize important home records.

HomeSafe Claims Manager is a simulated web application designed to help users organize their personal property, review insurance policy information, and submit and track claims from one place.

The application demonstrates how customers, insurance adjusters, and administrators can interact with the same system while receiving access to different information and actions based on their assigned roles.

Document Your Property

Create a home inventory containing important information about personal belongings, including descriptions, purchase dates, estimated values, categories, and serial numbers.

Review Your Policies

View simulated insurance policies, coverage periods, deductibles, coverage limits, and current policy statuses in an organized and easy-to-understand format.

Manage Your Claims

Submit claims against eligible policies and follow each claim as it moves through review, approval, payment, or denial.

Designed for Different Roles

HomeSafe Claims Manager uses role-based access so each account can only view and perform the actions appropriate for its role.

Users

Manage their home inventory, view their policies, submit claims, and monitor claim progress.

Adjusters

Review assigned claims, add notes, request information, and update claim statuses.

Administrators

Manage user accounts, policies, adjusters, claims, and other system records.

Project Purpose

This application is being developed as a personal software engineering project to practice full-stack web development, database design, authentication, authorization, validation, testing, and deployment.

The project is intended to demonstrate how a production-style business application can be organized using a layered backend, a relational database, and a responsive user interface.

Educational Project: HomeSafe Claims Manager is a simulated application. It does not issue real insurance policies or process real claims.
